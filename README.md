# Домашная работа 23 "Работа с ORM в Django"
## Цель домашней работы
Используя навыки, полученные в ходе изучения основ ORM и проектирования моделей, 
доработать html-сервер на основе фреймвока Django, 
подсоединив к нему базу данных и наполнив ее данными.
Так же подготовить административные инструменты сервера для работы с базой данных.

## Возможности приложения
+ Запуск простейшего сервера на локальном хосте на указанном порту;
+ Отображение и навигация нескольких html страниц с разным наполнением;
+ реакция на заполнение формы на странице контактов;

## Структура проекта
#### + Исходный код функционала приложения находится в папке приложения `catalog`
  + модуль `manage.py` - точка входа приложения, запуск веб-сервера;
#### + Шаблоны страниц находятся в папке `catalog/templates`

## Инструкции по использованию приложения
- Из каталога django22 запустите команду `python manage.py startserver`
