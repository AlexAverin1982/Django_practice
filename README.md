# Домашная работа 24 "Шаблонизация. Jinja2"
## Цель домашней работы
Используя навыки, полученные в ходе изучения основ шаблонизации, 
доработать шаблоны страниц на основе фреймвока Bootstrap и шаблонизатора Jinja2, 
исключив дублирование кода и внедрив его повторное использование базовых шаблонов и 
подшаблонов.
Так же начать разрабатывать собственные административные инструменты 
сервера для работы с базой данных.

## Возможности приложения
+ Запуск сервера сайта на локальном хосте на указанном порту;
+ Отображение и навигация нескольких html страниц с разным наполнением;
+ реакция на заполнение формы на странице контактов и создания товаров и категорий;

## Структура проекта
#### + Исходный код функционала приложения находится в папке приложения `catalog`
  + модуль `manage.py` - точка входа приложения, запуск веб-сервера;
#### + Шаблоны страниц находятся в папке `catalog/templates`
#### + Изображения товаров сохраняются в каталоге `catalog/static/images`

## Инструкции по использованию приложения
- Из каталога django22 запустите команду `python manage.py runserver`
